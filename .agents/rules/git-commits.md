# Git Commit Guidelines

When committing changes to Git, use concise, natural developer-style commit messages.

## Rules:
- Write the commit message based on the actual changes made.
- Keep it short, usually 3–8 words.
- Do not mention AI, ChatGPT, Gemini, Antigravity, automation, or "generated".
- Do not use unnecessary explanations.
- Avoid overly formal or generic wording.
- Prefer simple imperative messages.
- Do not add Co-authored-by lines unless explicitly requested.
- Do not modify Git author identity or impersonate another person.

## Examples:
- Fix OTP email delivery
- Update login validation
- Improve mobile navbar
- Add GitHub project links
- Fix dashboard layout
- Update API error handling
- Add responsive education section
- Remove unused dependencies
- Fix deployment configuration
- Update portfolio projects
